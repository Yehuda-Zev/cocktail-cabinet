Asteroids

Roles: Pilot (Player A) vs Asteroid Sender (Player B — "computer flies the ship, human sends the asteroids").

Planned: mirrors Snake's steerer/placer split. Computer pilot uses a steering strategy (avoid nearest threats, thrust toward open space) scaled by difficulty; computer sender picks spawn angle/speed/size scaled by difficulty, always respecting a minimum "fair spawn" distance from the ship so it's never an instant unavoidable hit.
